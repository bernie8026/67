EDUCATION PROGRAM // STEM

無人機教育課程

以「組裝 → 編程 → AI控制 → 飛行實作」為主線，向學校及教育機構提供工作坊、校本課程、比賽與導師培訓。

FILE / A-02 // COURSE
COURSE MODULES

課程內容

  • 無人機組裝工作坊：認識機體結構、零件、基本電子及安全操作。
  • 編程及AI控制：以程式控制飛行，逐步加入感測器、避障及AI辨識概念。
  • 校園飛行比賽：以任務、障礙賽及團隊挑戰增加實作及協作。
  • 科技展示：將學生作品及飛行成果轉化為校內或公開展示。
SCHOOL PACKAGE

學校與機構合作

可按學校程度、課時及設備數量設計校本方案，並提供導師培訓、教材、課程授權及技術支援。

工作坊

適合短期體驗、STEM Day及課外活動。

校本課程

導師培訓

協助學校建立可持續的內部教學能力。

課程授權
